Pro Editor · Help

What is the Pro Editor?

A full CapCut-style design studio baked into this portfolio. Every element on the page — headings, paragraphs, chips, buttons, badges, nav links, images, the avatar, even individual icons — is selectable, draggable, resizable, rotatable, recolorable, and animatable, live, in your browser. Edits auto-save to this browser, and you can save them permanently back to the HTML file.

Entering / exiting

  • Ctrl+Shift+EOpen the password gate
  • EnterSubmit the password from inside the gate
  • DoneTop-right button — leaves the editor and prompts you to save edits permanently to the HTML file

Selecting

  • ClickSelect any text/element
  • Shift+ClickAdd to multi-select
  • Drag empty areaMarquee-select many at once
  • EscDeselect

Moving & resizing

  • Drag bodyMove the element freely
  • Corner handlesResize from that corner
  • Edge handlesResize one side only
  • Top circleRotate (hold Shift to snap 15°)
  • Arrow keysNudge 1px (Shift = 10px)
  • Shift+dragConstrain to 15° angles

Smart guides

Pink lines show center/edge alignment with the viewport and other elements. Green lines show equal spacing. The element snaps when you're close.

Quick actions on selection

  • Red dot (top-right)Delete the element
  • Blue dotDuplicate
  • PadlockLock position (won't move until unlocked)
  • Dbl-clickEnter text-edit mode

Design panel (right)

  • PositionX / Y / W / H / rotation
  • TypographyFont family, size, weight, line-height, letter-spacing, text-align
  • ColorsText + background, with eyedropper presets
  • EffectsOpacity, blur, shadow, border-radius, filters
  • ArrangeAlign to page, distribute, z-order, lock, hide

Animation presets

One-click entrance animations (fade, slide, zoom, tilt, flip) applied to whatever is selected. The original scroll-reveal system is preserved.

Layers panel (left)

Reorder by drag, toggle visibility, lock, rename, delete. Like a real design tool's layers list.

Templates

One-click section templates — testimonial card, stat block, CTA banner, feature row — injected into the page for you to customize.

Saving edits permanently

  • Save to fileBlue button in the toolbar — writes your edits back to the HTML file. The first click asks you to pick the file; after that, every save writes silently to the same file. Requires Chrome or Edge (File System Access API).
  • Done buttonWhen you leave the editor, you'll be prompted to save your edits permanently to the file.
  • Ctrl+SForce-save to the current session (browser). Use the Save to file button to write the HTML file.
  • FallbackIf your browser doesn't support the File System Access API, Save to file downloads a copy you replace manually.

Export / Import

  • ExportDownloads a clean, single-file .html with all your edits baked in (a copy, doesn't touch the original)
  • ImportLoad a previously exported .json of your design state

Keyboard shortcuts

  • VMove tool
  • TText tool
  • LToggle layers
  • PToggle design panel
  • AAdd element menu
  • ?This help
  • Ctrl+Z / YUndo / redo
  • Ctrl+DDuplicate
  • Ctrl+GGroup (then drag together)
  • Ctrl+Shift+GUngroup
  • DeleteRemove selection
  • Ctrl+[ / ]Send backward / forward
  • Ctrl+SForce-save
  • Space+dragPan the page (when zoomed)

Device preview

Top-right toggle shows the page at desktop / tablet / mobile widths so your layout works everywhere.

Tips

  • Double-click any textEdit it inline
  • Right-click an elementContext menu: duplicate, lock, delete, bring forward
  • Hold Alt while draggingDisables smart-snapping for free placement
